# foundation

## Harness / prove / path norms
- Harness work should be repeatable from the repository root and fail clearly when required evidence is missing.
- Claims should be supported by runnable checks, recorded outputs, or concrete examples rather than manual assertion alone.
- Path references should remain repository-relative, stable, and free of machine-specific locations.
