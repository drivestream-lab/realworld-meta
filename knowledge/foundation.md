# foundation

## Harness / prove / path norms
- Harness work must be runnable, bounded, and reproducible, with evidence captured from real commands or checks.
- Proofs should record claim, evidence, verifier, and status; unverified claims remain explicitly unproven.
- Path norms keep next steps scoped to the current repo context, reversible, and free of new initiative or path creation.
